# Community Integrations

Third-party integrations and adapters built by the community on top of MyWhatsapp's REST API.

> **Looking for Chatwoot, Typebot, and other first-party integrations?** Those ship as official
> sandboxed plugins on the Integration Fabric — see the [MyWhatsapp-plugins](https://github.com/rmyndharis/OpenWA-plugins)
> catalog. This page lists only community-built projects.

> ⚠️ **These projects are community-maintained and are not affiliated with or endorsed by MyWhatsapp.**
> They may lag behind MyWhatsapp API changes. Verify compatibility and review the source before using
> them in production.

| Integration             | Platform                                                      | Source                                                                                                                                                     | Notes                                                                                                                                      |
| ----------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **ioBroker.mywhatsapp** | [ioBroker](https://www.iobroker.net/) (home / IoT automation) | [ThorstenBoettler/ioBroker.mywhatsapp](https://github.com/ThorstenBoettler/ioBroker.mywhatsapp) · [npm](https://www.npmjs.com/package/iobroker.mywhatsapp) | Send text / image / video / audio / document messages to chats and groups through MyWhatsapp's REST API, with Blockly blocks. Early stage. |

Maintain an integration built on MyWhatsapp and want it listed here? Open a PR adding a row (or an issue), including the repository link and a one-line description.
